# Sado Trade Bot

Sado Trade Bot은 업비트 코인 마켓과 미국 ETF 포트폴리오를 동시에 연구할 수 있는 전문 자동매매 실험실입니다. FastAPI 백엔드는 전략 시뮬레이션·실거래 실행·실시간 시황 API를 제공하고, 프론트엔드 대시보드는 8501 포트에서 고급 차트·뉴스·리스크 지표를 통합해 보여줍니다.

## 프로그램 요약 (한글)

- **전문가 수준 자동매매 엔진**: EMA 교차, 포지션 사이징, 스톱로스/테이크프로핏, 손익 지표 등 프로 트레이더가 쓰는 기능을 FastAPI 서비스로 제공합니다.
- **듀얼 포트폴리오 설계**: 안정형(미국 ETF)과 공격형(코인) 버킷을 동시에 관리하며, 목표 대비 초과·부족 금액과 리밸런싱 가이드를 한 번에 확인할 수 있습니다.
- **Synology 8501 대시보드**: 8501 포트 전용 UI에서 실시간 업비트 시황, 차트, 거래 로그, 위험 지표, 헬스 체크 배지를 동시에 모니터링해 사내 설비 모니터링 UX와 동일한 감각을 유지합니다.
- **프로 진단 패널**: API 엔드포인트부터 업비트 연결, 오토파일럿, 전략 엔진, 실거래 키 상태까지 전부 자동 점검해 컨테이너 장애를 조기에 감지하고 조치할 수 있습니다.
- **AI 시황 인텔리전스**: 업비트 캔들을 AI 엔진이 실시간 분석하여 레짐·추천 액션·신뢰도·리스크 제어안을 산출하고, BIS·IMF 등 권위 기관 뉴스와 함께 대시보드에 표시합니다.
- **AI 추천 TOP5 스캐너**: 업비트 전체 종목을 스캔해 신뢰도·추세·기관 센티먼트·돌파 확률을 점수화하고 상위 5개 코인을 실시간으로 추천합니다. 대시보드에서 재스캔 버튼으로 즉시 새 결과를 받아볼 수 있습니다.
- **AI 엣지 업그레이드**: 허스트 지수, ATR, 볼린저 밴드폭, 기관 센티먼트, 유동성 펄스를 합산해 돌파 확률과 변동성 국면을 정량화하고 오토파일럿 포지션 크기와 손절/테이크프로핏을 자동 조정합니다.
- **Synology Chat 실시간 알림**: 웹훅 URL(`SADO_CHAT_WEBHOOK`)을 등록하면 자동매매 체결·오류 이벤트가 Synology Chat으로 즉시 전송되어 설비 모니터링 룸에서도 상태를 추적할 수 있습니다.
- **다중 타임프레임 합의 분석**: 단·중·장기 구간을 동시에 평가해 합의된 추세와 일치율을 수치화하고, 오토파일럿·코파일럿 전략 근거와 리스크 모니터링에 바로 반영합니다.
- **AI 코파일럿 상담**: 질문형 인터페이스에서 전략·리스크·포지션 운용을 묻고 즉시 답변을 받아볼 수 있으며, AutoPilot 매매 플랜과 연동되어 실전/가상 계좌에 바로 활용 가능합니다.
- **무결성 및 검증 자동화**: `pytest` 기반 단위 테스트와 API 검증 루틴이 포함되어 있어 전략 수식과 포트폴리오 계산의 정확도를 반복 확인할 수 있습니다.
- **프로 리스크 스트레스 테스트**: 테이크프로핏·트레일링 스톱을 포함한 전문 포지션 제어와 몬테카를로 부트스트랩, 울서 지수·테일 비율 등 헤지펀드급 지표를 한 번에 제공합니다.
- **알파 브리핑 & 분포 분석**: 켈리 지수, 왜도·첨도, 평균 낙폭, 페인 인덱스, 최대 상승폭을 동시에 계산하여 전략 리포트를 전문가용 해설로 요약합니다.
- **실시간 시황 & 권위 뉴스**: 업비트 분봉/일봉 데이터를 실시간으로 분석하고 RSI·MACD·EMA 신호를 대시보드에 표시하며, IMF·BIS·글로벌 운용사 뉴스 RSS를 취합해 기관 브리핑을 제공합니다.
- **실거래/페이퍼 트레이딩 분리 운영**: 8501 대시보드에서 업비트 실거래 API와 가상 계좌를 라디오 버튼으로 전환하며 동일한 UI에서 주문/잔고를 관리할 수 있습니다.
- **실시간 페이퍼 하트비트**: 업비트 실시간 시세를 자동으로 페이퍼 브로커에 반영하고, 마지막 갱신 시각과 연결 상태 배지를 8501 콘솔에서 확인할 수 있어 가상 계좌가 실제 시장 흐름을 따라가는지 즉시 검증할 수 있습니다.
- **전략 마켓 선택 & 라이브 데이터**: 시뮬레이션 폼에서 원하는 업비트 마켓과 캔들 주기를 직접 지정하고, 체크박스 한 번으로 실시간 캔들을 불러와 실제 시장 데이터를 기반으로 전략을 검증할 수 있습니다.
- **업비트 마켓 디렉터리 & 가격 출처 표시**: `/market/list` 엔드포인트가 최신 마켓·경고·거래중지 정보를 내려주고, 8501 대시보드의 "업비트 마켓 탐색기"가 KRW/USDT/BTC 필터와 검색, 그룹 태그를 제공해 원하는 코인을 전략·페이퍼·오토파일럿·시황 패널에 즉시 적용합니다. 페이퍼 카드에서는 실시간/시뮬레이션/수동 가격 출처를 배지로 구분해 데이터 무결성을 한눈에 확인할 수 있습니다.
- **AI 오토파일럿 자동매매**: 업비트 캔들을 지속적으로 분석하고 신뢰도·포지션 한도를 만족하면 페이퍼/실거래 계좌에 자동 주문을 발동하며, 실행 로그·최근 주문·위험 상태를 8501 대시보드에서 즉시 확인할 수 있습니다.
- **쉬운 온보딩 문서**: 초보자용 흐름도와 배포 가이드를 제공하여 팀 내 어떤 구성원이라도 신속히 Synology 컨테이너에서 서비스를 기동할 수 있습니다.
- **웹훅 자가 테스트 패널**: 운영 상태 모니터에 Synology Chat 테스트 카드와 상태 뱃지가 추가되어 메시지를 입력해 전송을 검증하고, 최근 성공/실패 기록을 한눈에 확인할 수 있습니다.

## 한눈에 이해하는 쉬운 설명

1. **데이터 준비** – 백엔드가 업비트 시세나 랜덤 생성 데이터를 받아 EMA 전략을 돌릴 준비를 합니다.
2. **전략 시뮬레이션** – 사용자가 EMA 주기, 수수료, 초기 자본을 정하면 서버가 모든 거래 기록과 수익률을 계산합니다.
3. **결과 확인** – 프론트엔드 대시보드가 차트와 테이블로 손익, 리밸런싱 제안, 위험 지표, 몬테카를로 스트레스 테스트 결과를 시각화하여 보여줍니다.
4. **포트폴리오 설계** – 미국 ETF와 코인 비중을 입력하면 목표 대비 초과/부족 금액을 자동으로 계산해 조정 방향을 제시합니다.

즉, 프로그램은 "데이터 입력 → 자동 계산 → 대시보드 확인"의 흐름으로 동작하므로 초보자도 클릭 몇 번으로 전략을 반복 테스트할 수 있습니다.

## 구성 요소

- **backend/** – EMA 교차 전략, 포트폴리오 리밸런싱 로직, FastAPI 서비스
- **frontend/** – 최신 디자인의 싱글 페이지 대시보드 (Chart.js 기반 시각화, 전문가용 컨트롤 패널 UI 포함)
- **tests/** – 핵심 전략 함수 단위 테스트
- **requirements.txt** – 백엔드/프론트엔드 툴이 의존하는 파이썬 패키지 버전 고정
- **README.md** – 전체 사용 설명서와 배포 가이드

Synology 컨테이너나 로컬 개발 환경에서 동일한 구성을 재현하려면 아래 파일/폴더를 모두 준비하세요.

위 8개의 핵심 파일/디렉터리 외에 `README.md`(설명서)와 `.gitignore` 등 보조 파일을 추가하면 프로젝트 유지보수가 편리합니다.

## 빠른 시작

1. 의존성 설치
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. 백엔드 API 실행
   ```bash
   uvicorn backend.app:app --reload
   ```

3. Synology 컨테이너 또는 로컬 환경에서 `frontend/serve.py`를 이용해 8501 포트 대시보드를 실행합니다.
   ```bash
   # 예시: 로컬 개발 환경
   python frontend/serve.py
   ```
   `serve.py`는 모든 정적 자산에 `charset=utf-8` 헤더를 강제 적용하므로 한글이 깨지지 않으며, Synology 8501 포트에서도 동일한 폰트 품질을 유지합니다. 여기에 `/api/*` 요청을 FastAPI 백엔드로 역방향 프록시하는 기능을 추가해 외부에서는 8501 포트만 공개해도 됩니다. 내부 Docker 네트워크에서는 `http://backend:8000`으로 통신하고, 브라우저에서는 `http://<대시보드 호스트>:8501/api/...` 경로로 호출하므로 방화벽 정책을 단순화할 수 있습니다. 필요 시 프런트엔드 상단의 "운영 상태 모니터" 카드에서 엔드포인트를 수동으로 바꾸고, 바로 아래 Synology Chat 테스트/상태 카드로 웹훅 수신 여부와 최근 성공·실패 기록을 동시에 점검할 수 있습니다.

4. (선택) `.env` 파일로 민감 정보 관리 – 실거래 API 키를 사용할 경우 `cp .env.example .env`로 복사한 뒤 값을 채우고, `uvicorn --env-file .env backend.app:app --reload`처럼 실행하면 됩니다.

### Docker Compose로 올인원 실행

Synology 컨테이너 매니저에서 한 번에 백엔드(8000)와 대시보드(8501)를 띄우려면 다음 절차를 따라 주세요.

1. `.env.example`을 `.env`로 복사한 뒤 업비트 키나 대시보드 타이틀 등 필요한 값을 채웁니다. 민감 값이 없다면 기본 값으로 두어도 됩니다.
2. (선택) 구성 검증 – Synology UI에 복사하기 전에 로컬에서 아래 명령으로 Compose 문법을 점검할 수 있습니다.
   ```bash
   pip install pyyaml
   python - <<'PY'
import yaml
with open("docker-compose.yml", "r", encoding="utf-8") as fh:
    yaml.safe_load(fh)
print("docker-compose.yml syntax ok")
PY
   ```
3. 이미지 빌드와 실행
   ```bash
   docker compose build
   docker compose up -d
   ```
   - `backend` 서비스는 `backend/Dockerfile`을 기반으로 FastAPI와 테스트 의존성을 설치한 뒤 8000 포트에서 `uvicorn`을 기동합니다.
  - `frontend` 서비스는 `frontend/Dockerfile`을 이용해 정적 자산을 이미지에 포함시키고 8501 포트에서 `python serve.py`로 UTF-8 대응 HTTP 서버를 제공합니다.
4. 브라우저에서 `http://localhost:8501`에 접속해 대시보드가 정상적으로 뜨는지 확인합니다. 상단의 헬스 체크가 "ok"이면 백엔드 연동도 성공한 것입니다.
5. 로그는 `docker compose logs -f`로 실시간 확인하고, 종료 시 `docker compose down`을 실행합니다.

Synology 컨테이너 매니저에 복사할 때는 "Git 적용 복사"로 전체 프로젝트를 내려받은 뒤, `docker-compose.yml`, `backend/Dockerfile`, `frontend/Dockerfile` 세 파일을 함께 업로드해야 합니다. UI에서 `Map keys must be unique` 오류가 발생했다면 들여쓰기나 탭/공백 혼용 여부를 다시 확인한 뒤 위의 `yaml.safe_load` 검증 명령으로 문법을 체크하세요.

> Synology에 배포할 때는 `docker compose up -d` 이전에 `docker login`과 레지스트리 프록시 설정을 확인하여 사내 정책을 준수하세요.

### AI 오토파일럿 운용 가이드

1. **대시보드에서 즉시 제어** – 8501 포트의 "AI 오토파일럿 제어" 패널에서 모드(페이퍼/실거래), 분석 마켓, 캔들 주기, 리스크 성향, 평가 주기(초), 포지션 상한, 최소 신뢰도, 포트폴리오 참고 여부를 지정하고 `오토파일럿 시작`을 누르면 즉시 첫 번째 사이클이 실행됩니다. 실행 결과는 우측 카드에 최근 자동 주문, 경고 메시지, 로그 리스트로 표시됩니다.
2. **실거래 운용 요건** – 실거래 모드를 선택하려면 Synology 컨테이너에 `UPBIT_ACCESS_KEY`, `UPBIT_SECRET_KEY` 환경 변수를 설정해야 하며, 포트폴리오 참고 옵션을 활성화하면 AI 최적화 엔진이 자본 대비 권장 포지션과 헤지 노트를 함께 제공합니다.
3. **API로 자동화** – 동일한 기능은 FastAPI 엔드포인트로도 제어할 수 있습니다. 예시는 아래와 같습니다.
   ```bash
   curl -X POST http://localhost:8000/trading/autopilot/start \
     -H "Content-Type: application/json" \
     -d '{
       "mode": "paper",
       "market": "KRW-BTC",
       "interval": "minute60",
       "risk_appetite": 0.6,
       "capital": 30000000,
       "poll_interval": 120,
       "max_position_pct": 0.25,
       "min_confidence_pct": 60,
       "include_portfolio": true
     }'
   ```
   - 상태 조회: `GET /trading/autopilot/status`
   - 중지: `POST /trading/autopilot/stop`
4. **로그와 리스크 확인** – API 응답과 대시보드 모두 자동매매 로그(`level`, `message`, `timestamp`), 마지막 실행 지표, 최근 자동 주문 세부정보(모드/매수·매도/수량/가격/메모)를 포함하므로, 가상 계좌/실거래 계좌가 실제로 매매를 수행했는지 즉시 검증할 수 있습니다.

### 전문가용 전략 파라미터 & 리포트 확장

- `take_profit_pct`: 목표 수익률을 지정하면 해당 지점에 도달하는 즉시 청산하여 변동성 속에서도 확정 수익을 확보합니다.
- `trailing_stop_pct`: 최고가 대비 하락폭을 감지해 자동으로 수익을 잠그고 추세 반전을 방어합니다.
- `market` / `interval`: 업비트 마켓 코드(KRW-BTC 등)와 캔들 주기를 선택하면 실전과 동일한 데이터셋으로 전략을 검증할 수 있습니다.
- `use_live_data`: 체크하면 최신 업비트 캔들을 자동으로 다운로드하고, 네트워크가 불안정하면 시뮬레이션 데이터로 자동 대체합니다.
- `trade_summary`에는 평균 승/패율, 중앙값 수익률, 최대 손실·수익, 승패 비율이 추가되어 투자위원회 보고서 수준의 데이터가 제공됩니다.
- `monte_carlo_summary`는 거래 수익률을 부트스트랩해 5%/50%/95% 분위를 제시하며, 울서 지수·회복 계수·테일 비율 같은 헤지펀드급 리스크 지표가 함께 대시보드에 노출됩니다.
- 대시보드에는 오메가 비율, 켈리 지수, 연속 승/패 스트릭 카드가 추가되어 포트폴리오 베팅 비중과 연속 손실 리스크를 정량적으로 판단할 수 있습니다.
- 2024년 2월 알파 확장: 왜도·첨도, 평균 낙폭, 페인 인덱스, 최대 상승폭을 새로 계산하고 "알파 브리핑" 패널에서 켈리 지수와 함께 전략 운용 인사이트를 자동 요약합니다.

- **EMA 전략 시뮬레이션**: Fast/Slow EMA 조합, 수수료, 초기 자본을 조정하며 자동매매 전략 성능을 검증합니다.
- **포지션 사이징 & 리스크 관리**: 거래당 허용 위험률과 스톱로스 폭을 지정해 포지션 크기를 자동으로 제어합니다.
- **프로 포지션 제어**: 테이크프로핏과 트레일링 스톱을 병행해 상승 추세 잠금을 지원하고, 거래별 청산 사유를 기록해 리스크 리뷰가 용이합니다.
- **시세 자동 생성**: 클릭 한 번으로 시드 기반 랜덤 시세를 생성하여 백테스트를 반복할 수 있습니다.
- **리밸런싱 추천**: 현재 보유 자산과 목표 비중을 입력하면 매수/매도 금액을 자동 계산합니다.
- **트레이드 로그**: 각 거래의 진입/청산, 수익률, 보유 봉수, PnL을 테이블로 제공합니다.
- **고급 UX**: Pretendard 폰트, 글래스모피즘 스타일, 반응형 레이아웃으로 전문가용 컨트롤 센터 경험을 제공합니다. 대시보드 헤더와 문구는 "Sado Trade Bot"으로 통일했습니다.
- **AI 포트폴리오 아키텍트**: 위험 성향·투자 자본·선호 마켓만 입력하면 AI가 안정형 ETF와 공격형 코인 비중을 자동 계산하고 예상 수익/변동성·샤프·테일 리스크 가드와 함께 제시합니다.
- **리치 대시보드**: 차트, 거래 내역 테이블, 포트폴리오 카드가 한 화면에 구성되어 있어 전략가가 즉시 의사결정을 내릴 수 있습니다.
- **리스크 애널리틱스**: 연간 변동성, 샤프/소르티노, 칼마, 95% VaR, 프로핏 팩터, 기대수익률 등 전문가 지표를 실시간으로 제공합니다.
- **알파 브리핑**: 왜도/첨도 기반 분포 분석과 켈리·페인 인덱스·최대 반등폭을 조합한 텍스트 요약으로 전략 리스크 포인트를 즉시 확인합니다.
- **몬테카를로 스트레스 테스트**: 거래 수익률을 부트스트랩해 5%/50%/95% 퍼센타일을 제시하고, 울서 지수·테일 비율·회복 계수 등 헤지펀드급 위험지표를 함께 제공합니다.
- **운영 상태 모니터링**: Synology 컨테이너 8501 포트에 맞춘 API 엔드포인트 입력창과 헬스 체크 배지를 통해 연결 무결성을 즉시 확인할 수 있습니다. Synology Chat 테스트/상태 카드로 웹훅 전송과 최근 성공·실패 로그도 곧바로 검증 가능합니다.
- **위험 프로파일 포트폴리오 설계**: 안정형 미국 ETF와 공격형 코인 자산을 동시에 고려하는 듀얼 버킷 알고리즘을 제공하고, 예상 수익/변동성/다변화 지수를 계산합니다.
- **실거래 & 페이퍼 트레이딩 콘솔**: 업비트 API 키가 설정되어 있으면 실거래 주문을, 키가 없을 때는 가상 계좌를 안전하게 검증할 수 있도록 이중화된 실행 패널을 제공합니다. 페이퍼 모드는 API 키 없이도 언제든지 동작하며, 실시간 하트비트 배지가 마지막 갱신 시각과 연결 품질을 알려줍니다.
- **실시간 업비트 시황 API**: `/market/upbit/candles`와 `/market/upbit/insights` 엔드포인트가 최신 분봉/일봉 데이터를 불러와 EMA·RSI·MACD 지표와 권장 액션을 계산해 반환합니다.
- **AI 추천 TOP5**: `/market/recommendations` 엔드포인트가 업비트 전 종목을 분석해 신뢰도·추세·기관 센티먼트 기반 상위 코인을 반환하며, 대시보드는 기준 통화·주기 필터와 재스캔 버튼을 제공합니다.
- **업비트 마켓 인덱스 API**: `/market/list` 엔드포인트가 현재 거래 가능한 KRW 마켓과 경고 여부, 거래 정지 상태를 내려주어 대시보드 자동 완성과 외부 전략 서비스에서 동일한 종목 테이블을 사용할 수 있게 합니다.
- **기관 뉴스 브리핑**: `/market/news` 엔드포인트가 IMF·BIS·ETF 운용사 RSS를 우선 수집하고, 네트워크가 불안정할 때는 신뢰도 높은 큐레이션 목록으로 대체합니다.
- **질문형 AI 코파일럿 & AutoPilot**: `/ai/copilot` 엔드포인트가 사용자의 질문, 현재 마켓, 트레이딩 모드(실거래/페이퍼)를 조합해 코파일럿 답변과 AutoPilot 매매 플랜을 동시에 제공합니다. 대시보드의 "AI 코파일럿" 패널에서 바로 질문을 입력하면 핵심 요약, 실행 체크리스트, 리스크 경고, 포트폴리오 하이라이트가 한 번에 갱신됩니다.
- **Synology Chat 상태 API**: `/notifications/chat/status` 엔드포인트가 웹훅 설정 여부, 마지막 전송 시각, 최근 오류 메시지를 반환해 원격 자동화에서도 알림 채널 상태를 확인할 수 있습니다.

## 실거래 & 페이퍼 트레이딩 운용 방법

1. **환경 변수 설정** – 업비트 실거래를 사용하려면 `.env`에 `UPBIT_ACCESS_KEY`, `UPBIT_SECRET_KEY`, (선택) `UPBIT_BASE_URL`을 입력하고 `uvicorn --env-file .env backend.app:app`으로 서버를 기동하세요. Synology Chat으로 체결/경고를 받고 싶다면 동일한 `.env`에 `SADO_CHAT_WEBHOOK=https://chat.example.com/webhook/...` 형식의 URL을 추가하세요. 업비트 외부망이 차단된 공장망이나 프록시 지연이 심한 환경에서는 `UPBIT_ENABLE_NETWORK=0`을 지정하면 백엔드가 즉시 합성 시세로 전환하여 대시보드 타임아웃을 방지합니다.
2. **대시보드에서 모드 선택** – "실거래 & 페이퍼 트레이딩 콘솔" 패널의 라디오 버튼을 이용해 `페이퍼 트레이딩` 또는 `실거래 (Upbit)`를 선택합니다.
3. **주문 입력** – 마켓, 방향, 주문 유형, 수량/가격을 입력 후 `주문 실행` 버튼을 누르면 백엔드 `/trading/order` API가 호출됩니다.
   - 페이퍼 모드에서는 `PaperBroker`가 즉시 체결·잔고·실현손익을 계산하고, 결과가 대시보드 카드에 JSON으로 표시됩니다.
   - 실거래 모드에서는 업비트 REST API `/v1/orders`를 호출하여 실제 주문 UUID와 상태를 반환합니다. 키가 잘못되었을 경우 400 오류와 상세 메시지를 즉시 확인할 수 있습니다.
4. **실시간 연동 확인** – 실시간 업비트 시황 패널이 최신 종가를 자동으로 페이퍼 계좌에 반영하고, 하트비트 배지가 다음 상태로 전환되며 마지막 업데이트 시각을 함께 표시합니다.
   - `실시간 연동`: 90초 이내에 업비트 시세를 수신해 완전히 동기화되었습니다.
   - `연동 지연`: 5분 이내 지연으로 재시도가 필요합니다.
   - `시뮬레이션 시세`: 업비트 연결 실패 시 자동 생성된 synthetic 데이터로 대체되었습니다.
   - `수동 동기화`: 사용자가 `시세 반영` 폼으로 직접 입력한 값이 반영되었습니다.
   - `상태 확인 필요`: 10분 이상 갱신이 없거나 시각 파싱이 실패했을 때 노출됩니다.
5. **계좌 관리** – `계좌 리셋`(초기 자본 재설정), `시세 반영`(수동 종가 업데이트), `잔고 조회`(실거래 잔고 확인) 버튼으로 페이퍼/실거래 계좌 상태를 분리해 점검할 수 있습니다.
6. **무결성 테스트** – `pytest`는 페이퍼 브로커 매매 사이클과 실거래 키 검증을 자동화하여, 컨테이너 빌드 후에도 동일한 행동을 보장합니다.

### 업비트 마켓 탐색기 사용법

- 8501 대시보드의 "업비트 마켓 탐색기" 패널에서 검색창에 티커, 한글/영문 이름, 심볼을 입력하면 즉시 필터링됩니다.
- `KRW`, `USDT`, `BTC`, `전체` 칩으로 기준 통화를 전환하고, 경고/거래중지 그룹 버튼을 눌러 리스크가 있는 종목만 별도로 확인할 수 있습니다.
- 목록에서 원하는 코인의 `전략`, `페이퍼`, `오토파일럿`, `시황`, `수동 주문` 버튼을 누르면 각각 EMA 시뮬레이션, 페이퍼 계좌, 오토파일럿 패널, 실시간 시황 카드, 주문 폼이 해당 마켓으로 즉시 전환됩니다.
- 서버가 업비트에 접근하지 못해도 대표 종목(Fallback)이 자동으로 채워지므로 Synology 오프라인 환경에서도 동일한 UX를 유지할 수 있습니다.

### AI 추천 TOP5 스캐너 사용법

- 8501 대시보드의 "AI 추천 TOP5" 패널은 기본적으로 KRW 마켓, 60분 봉 기준 상위 5개 코인을 자동으로 제안합니다.
- 상단 칩으로 `KRW/USDT/BTC/전체`를 전환하면 즉시 필터가 반영되며, `재스캔` 버튼을 눌러 최신 데이터를 강제로 계산할 수 있습니다.
- 각 추천 카드에는 신뢰도, 추세 강도, 변동성, 기관 센티먼트, 돌파 확률, 최근 가격 변동과 종가가 함께 표시되어 가상/실거래 전략에 바로 활용할 수 있습니다.
- API를 직접 호출하려면 `GET /market/recommendations?base=ALL&interval=minute15&limit=5`처럼 기준 통화와 캔들 주기를 지정하면 되며, 응답에는 분석 소스(upbit/synthetic/mixed)와 에러 로그가 함께 포함됩니다.

### Synology Chat 웹훅 검증

- 환경 변수에 `SADO_CHAT_WEBHOOK` 또는 `SYNOLOGY_CHAT_WEBHOOK`을 설정하면 백엔드와 오토파일럿이 체결/오류 메시지를 자동 전송합니다.
- 대시보드 상단 "Synology Chat 웹훅 테스트" 카드에서 테스트 문구를 입력하고 `테스트 전송`을 누르면 `/notifications/chat` API가 호출되며 성공/실패가 배지로 표시됩니다.
- 같은 카드의 상태 문구는 `/notifications/chat/status` 응답을 반영하여 최근 전송 메시지, 성공 시각, 오류 원인을 보여주므로 Synology Chat 연결이 정상인지 실시간으로 확인할 수 있습니다.
- 테스트가 실패할 경우 8501 우측 상단 API 엔드포인트 입력창에서 백엔드 주소가 올바른지 확인한 뒤 다시 시도하세요.
- 서버 쉘에서는 `python -m backend.notifications --status` 명령으로 환경 변수 구성 여부와 최근 전송 기록을 확인하거나, `python -m backend.notifications "Synology Chat 웹훅 테스트"`로 직접 메시지를 발송하여 채널에서 수신 여부를 검증할 수 있습니다.

### AI 코파일럿 활용 가이드

1. **질문 입력** – 대시보드 "AI 코파일럿 실시간 자문" 패널에서 전략/리스크 관련 질문을 한국어 또는 영어로 입력합니다.
2. **리스크 성향 지정** – 슬라이더로 리스크 성향(0~1)과 투자 자본을 지정하면 AutoPilot 포지션 규모가 자동 조정됩니다.
3. **AutoPilot 플랜 확인** – 코파일럿이 생성한 답변과 함께 매매 방향, 신뢰도, 손절/테이크·트레일링 스톱, 모니터링 체크리스트가 카드로 정리됩니다.
4. **포트폴리오 하이라이트** – AI가 추천한 듀얼 버킷 포트폴리오 상위 비중과 헤지 노트를 확인하고, 필요 시 `/ai/portfolio/optimize`로 상세 계획을 재계산합니다.
5. **API 직접 호출** – 외부 시스템에서 활용하려면 `POST /ai/copilot`에 아래 예시처럼 JSON을 전달하세요.
   ```bash
   curl -X POST "http://127.0.0.1:8000/ai/copilot" \
     -H "Content-Type: application/json" \
     -d '{
           "question": "현재 KRW-BTC 매수 타이밍인가?",
           "market": "KRW-BTC",
           "interval": "minute60",
           "mode": "paper",
           "risk_appetite": 0.6,
           "capital": 20000000,
           "include_portfolio": true
         }'
   ```
   응답에는 `answer`, `summary_points`, `risk_notices`, `autopilot` 구조화 플랜, `insight`(EMA/RSI/MACD 등), `news`가 포함되어 외부 리포트나 사내 슬랙 봇에 바로 연동할 수 있습니다.

## 테스트

단위 테스트는 `pytest`로 실행합니다.
```bash
pytest
```

`pytest`에는 다음과 같은 추가 검증이 포함되어 있습니다.

- `docker-compose.yml`이 PyYAML 파서를 통과하는지 확인하여 Synology UI에서 발생하던 `Map keys must be unique`류 오류를 사전에 차단합니다.
- 각 소스 파일에 Git 패치 접두사(`+`)가 남아 있지 않은지 검사하여 "패치 복사"를 잘못 적용했을 때 즉시 감지합니다.
- `tests/test_notifications.py`가 Synology Chat 웹훅 스텁과 `/notifications/chat` 엔드포인트를 검증해 알림 기능이 배포 전에 정상 작동하는지 확인합니다.
- `tests/test_execution.py`는 페이퍼 브로커의 매수/매도/시세 반영 흐름과 `/trading/order`, `/trading/paper/*` API가 올바르게 동작하는지 확인하고, 실거래 모드가 환경 변수 없을 때 안전하게 거부되는지 검증합니다.

프런트엔드와 백엔드는 각각 8501/8000 포트에서 동작하도록 설계되었으므로, Synology 컨테이너나 Docker Compose 환경에서도 동일한 구성을 유지하면 무결성 검증이 수월합니다.

`.env`에 저장한 값은 테스트 실행 시 자동으로 주입되지 않으므로, 실거래 키가 필요한 커스텀 테스트를 추가한다면 `export UPBIT_ACCESS_KEY=...`처럼 환경 변수를 먼저 선언하거나 `python-dotenv` 패키지를 추가해 수동으로 로드하세요.

## Visual Studio Code에서 프로젝트 복사하는 법

자동매매 실험실을 직접 수정하려면 아래 순서를 따라 Visual Studio Code(우측 점 세 개 메뉴 활용)에 파일을 구성하세요.

1. **리포지토리 폴더 생성** – 로컬 PC에 빈 폴더를 만들고 Visual Studio Code에서 `파일 → 폴더 열기`로 해당 폴더를 선택합니다.
2. **터미널 열기** – VS Code 하단의 `터미널` 탭을 열어 `git clone` 명령으로 이 저장소를 복제하거나, 제공된 소스 파일을 복사하려면 새 파일을 생성할 디렉터리로 이동합니다.
3. **우측 점 세 개 메뉴 활용** – VS Code 탐색기에서 폴더 이름 옆에 있는 `…` 버튼을 클릭한 뒤 `새 파일` 또는 `새 폴더`를 선택하여 `backend/`, `frontend/`, `tests/` 등 필요한 구조를 만듭니다.
4. **파일 붙여넣기** – README, `app.py`, `trading.py` 등 각 파일을 선택한 뒤 에디터 창에 소스 코드를 붙여넣고 저장합니다.
5. **유효성 검증** – VS Code 터미널에서 `python -m venv .venv && source .venv/bin/activate` 후 `pip install -r requirements.txt`를 실행하고, `pytest`와 `uvicorn backend.app:app --reload`로 코드 무결성과 실행 상태를 확인합니다.
6. **Git 적용** – 다시 탐색기의 `…` 버튼에서 `소스 제어 보기 열기`를 선택하고, 변경된 파일을 스테이징(`+`) 후 커밋 메시지를 입력하여 버전에 반영합니다.

이 과정을 거치면 Synology 컨테이너에 올리기 전에도 로컬에서 구조와 테스트를 동일하게 재현할 수 있습니다.

### "Git 적용 복사"와 "패치 복사" 중 무엇을 쓸까?

Synology 컨테이너나 VS Code 환경으로 **프로젝트 전체를 그대로 옮기고 싶다면 반드시 Git 기반 복사** 절차를 사용하세요. 인터페이스에 따라 "Git 적용 복사"처럼 전체 리포지토리를 복제하는 기능이 제공되는데, 이 방식을 이용하면 다음과 같은 이점이 있습니다.

- **모든 파일과 폴더 유지**: `.env.example`, `docker-compose.yml`, `tests/` 등 숨김 파일과 서브 디렉터리까지 누락 없이 내려받습니다.
- **커밋 히스토리 보존**: 변경 이력을 함께 가져오므로 문제가 생겼을 때 이전 버전으로 쉽게 되돌릴 수 있습니다.
- **무결성 검증 용이**: `git status`, `pytest` 등 표준 명령어로 바로 검증하고 배포하기 좋습니다.

반대로 "패치 복사"는 특정 변경 사항만 텍스트로 추출해 적용하는 방식이라 **일부 파일만 복사되거나 디렉터리 구조가 깨질 수 있습니다**. 이미 로컬에 동일한 리포지토리가 있고 특정 수정만 반영할 때 사용하는 용도이므로, 처음 프로젝트를 구성하거나 컨테이너로 옮기는 상황에는 적합하지 않습니다.

> 요약: **전체 구성을 복사해야 한다면 `git clone` 또는 "Git 적용 복사"를 선택**하고, "패치 복사"는 이미 존재하는 프로젝트에 부분 수정사항을 붙여 넣을 때만 사용하세요.
