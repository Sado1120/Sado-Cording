# 외부 벤치마크 적용성 심화 분석

본 문서는 크레온 로보어드바이저와 CryptoHopper에서 관찰한 기능을 기반으로, Sado Trade Bot에 어떤 요소를 즉시 반영하고 어떤 항목을
중장기 과제로 남길지 심화 분석한 결과를 정리합니다. 각 기능은 (1) 이미 구현됨, (2) 단기 적용 가능, (3) 중장기 연구 필요, (4) 비적용
으로 분류했습니다.

## 2. 적용 로드맵 제안

### 2.1 즉시 착수 (다음 스프린트)
- **위험 성향 설문**: `frontend/app.js`에 온보딩 설문 컴포넌트를 추가하고, `backend/ai.py`에 위험 점수 → 자산 배분 매핑을 위한 테이블을
  도입합니다.
- **자동 리밸런싱 스케줄링**: `backend/autopilot.py`에 리밸런싱 주기와 허용 오차를 포함한 작업 큐를 설계하고, Synology Chat으로 실행
  결과를 전송합니다.
- **외부 시그널 어댑터**: `backend/market.py`에 RSS/REST 시그널 입력 어댑터 인터페이스를 추가하고, 권위 있는 기관의 시세 코멘트를
  캡슐화합니다.
- **온보딩 마법사/상단 링크 강화**: CryptoHopper의 온보딩 UX를 참고해 대시보드 첫 접속 시 필수 설정을 안내하는 모달과 빠른 실행
  링크를 제공합니다.

### 2.2 중기 계획 (3~4 스프린트)
- **전략 디자이너 DSL**: EMA 외에 RSI, MACD, 볼린저 밴드 등을 조합할 수 있는 규칙 기반 DSL을 `backend/trading.py`에 도입하고,
  프런트엔드에서 드래그 앤 드롭 혹은 조건 카드 조합 UI를 개발합니다.
- **전략 템플릿 공유/카피트레이딩**: 전략 설정을 JSON으로 내보내고, Synology 조직 내부에서 불러와 복제할 수 있는 저장소 기능을 추가합니다.
- **월별/분기별 성과 리포트 자동 배포**: 오토파일럿 로그를 요약해 PDF 혹은 HTML 보고서로 생성하고, Synology Chat·이메일로 전달하는
  파이프라인을 구성합니다.
- **다중 채널 알림**: Synology Chat 외 Slack, Telegram, 이메일로 확장 가능한 알림 어댑터 프레임워크를 설계합니다.

### 2.3 장기 연구 과제
- **전략 마켓플레이스**: 사내/파트너 간 전략을 구독·판매하는 생태계 구축은 보안·정산 체계가 필요하므로 장기 과제로 분류합니다.
- **규제 준수/투자자 보호 체계**: 크레온이 준수하는 금융 규제와 유사한 체크리스트를 마련해 실거래 확장 시 필요한 법적 요건을 검토합니다.
- **멀티 거래소 확장**: CryptoHopper처럼 글로벌 거래소를 동시에 연동하려면 브로커 추상화와 환율·세제 모듈이 필요하므로 별도 프로젝트로
  분리합니다.

## 3. 결론
- 핵심 벤치마크 기능 중 상당수는 이미 구현되었거나, 단기 작업으로 Sado Trade Bot에 흡수할 수 있습니다. 특히 위험 성향 설문, 자동
  리밸런싱, 외부 시그널 어댑터, 온보딩 마법사는 다음 배포에 포함시키는 것이 좋습니다.
- 전략 디자이너 및 템플릿 공유처럼 대규모 UI/백엔드 확장이 필요한 항목은 별도의 설계 스프린트를 마련해 단계적으로 추진합니다.
- CryptoHopper의 클라우드 24/7 운영, 마켓플레이스, 다중 거래소 지원은 인프라와 규제 이슈가 동반되므로 장기 로드맵에서 다루되,
  현재 Synology 환경에 맞는 안정화와 자동매매 신뢰도 향상에 우선 집중합니다.

향후 새로운 외부 서비스를 조사할 때에도 동일한 분류 체계를 사용하면, 기능 도입 우선순위를 일관되게 관리할 수 있습니다.
