# XM 프리미엄 트레이딩 벤치마크 메모

본 메모는 XM 글로벌 트레이딩 플랫폼([링크](https://www.xm.com/landing/promo-shares/kr?gid=254741&gad_source=1&gad_campaignid=22755314794&gbraid=0AAAAADQ7mB2EHfErg-GcXzx6bagyn2aI2&gclid=CjwKCAjw6vHHBhBwEiwAq4zvA2XuKDmRNsyzN8S00oae0Q_yYhGkSHArIdxU2soJigHI9DZQ82ePvRoCwtIQAvD_BwE))의 공개 콘텐츠를 검토하며 Sado Trade Bot에 접목할 수 있는 아이디어를 정리한 것입니다. 외부 서비스와의 직접 연동 없이, 우리 프로그램이 제공해야 할 프리미엄 경험을 정의하는 참고자료로 사용합니다.

## 핵심 벤치마크 포인트

1. **다중 자산 교육 및 리서치 허브**  
   * XM의 교육 페이지가 강조하는 실전 전략, 웨비나 요약, 경제 캘린더 안내를 참고해 대시보드 뉴스/인사이트 모듈이 “기관 브리핑”과 “AI 리포트”를 동시에 제공하도록 설계합니다.  
   * README와 대시보드 문구에서 AI 자가 진단, 위험 지침, 투자 스토리텔링 기능을 명시해 프로 트레이더 수준의 신뢰도를 전달합니다.

2. **기술 지표 + 패턴 + 거래량 결합 신호**  
   * XM 전략 가이드의 MACD/RSI/볼린저/거래량 조합 아이디어를 바탕으로, `TechnicalConfluence` 점수를 도입했습니다.  
   * 점수는 추세 강도, MACD 가속, RSI 위치, 밴드 스퀴즈, 거래량 확인, 캔들 패턴을 통합 평가하여 프리미엄 알고리즘을 제공합니다.

3. **프리미엄 리스크 관리**  
   * XM이 강조하는 포지션 크기, 손절·익절, 변동성 기반 조정을 AutoPilot 계획에 반영했습니다.  
   * Synology Chat 다이제스트, 자가 복구, 무결성 배지 등 운영 보호 장치로 “24시간 자동 복구” 이미지를 강화합니다.

4. **맞춤형 알림과 데일리 다이제스트**  
   * XM의 데일리 브리핑을 벤치마킹하여, Synology Chat으로 컨플루언스/오토파일럿 요약을 묶어 발송하는 다이제스트 모드를 강화합니다.  
   * 긴급 이벤트(실거래 체결, 위험 경고)만 즉시 알림으로, 일반 시황은 리포트 형태로 전달합니다.

| --- | --- | --- |

| 리스크 관리 | 변동성·포지션 관리 교육 | AutoPilot 포지션 조정, Synology Chat 긴급 경보 + 다이제스트 |
| UI/UX | 프리미엄 교육 허브 | README/대시보드에 전문 용어, 기관 브리핑, 자가 진단 노출 |
| 운영 안정성 | 24시간 고객 지원/복구 | 업비트 자가 복구, 무결성 배지, 테스트 스위트 강화 |

## 향후 보강 아이디어

* XM의 테마 포트폴리오 소개처럼, AI 추천 코인/ETF 조합을 “테마 카드” 형태로 제공하는 것을 검토합니다.
* 경제 캘린더/거시 이벤트 피드를 접목해, AutoPilot이 이벤트 전에 포지션을 줄이도록 자동화할 수 있습니다.
* 사용자 온보딩 체크리스트(위험 성향 설문, API 키/웹훅 검증) 흐름을 강화하여 초보자도 빠르게 프로 세팅을 복원하도록 합니다.
