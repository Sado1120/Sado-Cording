# Creon Robo Advisor Benchmark

본 문서는 대신증권의 **크레온 로보어드바이저** 서비스가 공개적으로 알려진 기능을 바탕으로 Sado Trade Bot의 고도화 과제를 정리한 벤치마크 메모입니다. 실제 사이트 및 API는 본 저장소에서 직접 접근하지 않았으며, 아래 내용은 제공된 레퍼런스 자료와 금융 로보어드바이저 업계의 일반적인 기능을 참고하여 정리한 것입니다.

## 핵심 특징 요약

| 영역 | 크레온 로보어드바이저 특징(공개 자료 기준) | Sado Trade Bot 대응 방안 |
|------|----------------------------------------|---------------------------|
| 포트폴리오 구성 | 위험 성향 설문을 바탕으로 모델 포트폴리오(국내외 ETF, 펀드)를 자동 추천 | 기존 듀얼 버킷 설계에 위험 성향 설문 모듈을 추가하고 AI 최적화 엔진과 연계 |
| 리밸런싱 | 시장 상황에 따라 주기적인 비중 조정 | 백엔드 스케줄러/오토파일럿에 리밸런싱 주기 옵션과 자동 실행 로그 추가 |
| 리스크 관리 | 손절/이탈 기준, MDD 모니터링 | 이미 제공 중인 스톱로스·테일 지표를 강화하고, MDD 경보를 Synology Chat으로 통지 |
| 실시간 모니터링 | 시장 시황/뉴스/알림 제공 | AI 시황·뉴스 모듈을 고도화하여 동일한 사용자 경험 제공 |
| 사용자 가이드 | 투자 과정 안내, 백테스트 자료 | 대시보드 온보딩 모드 및 샘플 시나리오 안내 추가 |

## 벤치마킹 액션 아이템

1. **위험 성향 설문 및 모델 포트폴리오 라이브러리**
   - UI: 대시보드에 설문 위젯과 모델 포트폴리오 프리셋 선택 기능 추가
   - 백엔드: `backend/ai.py`에 위험 점수 → 자산 비중 매핑 테이블 도입
2. **자동 리밸런싱 일정화**
   - 오토파일럿 스케줄러에 리밸런싱 주기/허용 오차 설정 추가
   - Synology Chat으로 리밸런싱 결과 전송
3. **리스크 경보 체계**
   - MDD·변동성·손실 확대 시 즉각 알림 발송
   - 대시보드 상단 배지에 위험 등급 표시
4. **시나리오/보고서 제공**
   - 투자 계획 및 과거 성과를 PDF/HTML 보고서로 생성하는 기능 검토
   - README에 사용자 온보딩 절차 보강

## 향후 연구 항목

- 크레온 서비스와 동일한 **규제 준수**(적합성 원칙, 투자자 보호)를 위한 체크리스트 작성
- **K-IFRS/세제 고려** 자동 보고서를 위한 세전/세후 계산 모듈 도입
- 대신증권 API 연동 여부 검토: Upbit와 동일하게 REST 기반인지 확인 후, 다중 브로커 추상화 모듈 확장

> **주의**: 본 문서는 참고용이며, 실제 크레온 서비스와의 기능 동등성을 보장하지 않습니다. 향후 추가 정보가 확보되면 내용을 갱신하세요.
