# Sado Trade Bot 하드 모드 코드 검증 보고서

## 1. 분석 개요
- **목표**: 기존 커밋으로 제공된 자동매매 프로그램이 실제 구현을 기반으로 하고 있는지, 할루시네이션 없이 전문적인 매매 로직을 담고 있는지 검증.
- **방법**: 핵심 모듈(자동매매 루프, AI 분석, 가상 브로커, 테스트 코드)을 정적 리뷰하고, 전 범위 `pytest`로 회귀 검증 실행.

## 2. 핵심 구조 진단
### 2.1 오토파일럿 실행 루프
- `backend/autopilot.py`의 `AutoTrader.run_cycle`은 추천 종목을 순환하며 캔들 데이터를 가져오고, 무결성 점수 60점 미만 종목은 즉시 제외합니다.【F:backend/autopilot.py†L234-L371】
- 실행 가능한 시그널을 찾으면 `AutoTrader._maybe_execute`가 포지션 비중·신뢰도를 점검하고 모드에 따라 페이퍼 또는 실거래 주문 경로로 분기합니다.【F:backend/autopilot.py†L574-L605】
- 페이퍼 주문 시 `PaperBroker`에 매수/매도 지시를 내려 잔고·현금이 즉시 업데이트됩니다.【F:backend/autopilot.py†L607-L640】【F:backend/execution.py†L82-L199】

### 2.2 AI 시황·시그널 생성
- `backend/ai.py`의 `analyse_market`은 EMA, RSI, MACD, ATR, 볼린저 밴드, 허스트 지수, 유동성 펄스, 급등락 지표 등을 계산해 매수/매도 권고를 도출합니다.【F:backend/ai.py†L702-L916】
- 동일 함수는 컨플루언스 점수, 급등락 감지, 기관 뉴스 신뢰도까지 포함한 요약을 반환해 대시보드와 오토파일럿이 동일 정보를 공유할 수 있게 합니다.【F:backend/ai.py†L894-L931】

### 2.3 가상 브로커와 주문 처리
- `PaperBroker`는 초기 현금, 수수료, 평균 단가 관리, 시장가·지정가 처리 등 실제 브로커의 기본 기능을 모두 구현합니다.【F:backend/execution.py†L79-L199】
- 잔고 스냅샷에는 현금, 포트폴리오 평가액, 보유 포지션 목록이 포함돼 수익률 계산 근거를 제공합니다.【F:backend/execution.py†L200-L210】

### 2.4 테스트 커버리지
- `tests/test_autopilot.py`는 오토파일럿이 시작 즉시 매수 주문을 집행하고 로그·다음 사이클 시간·잔고 변화를 검증합니다.【F:tests/test_autopilot.py†L90-L177】
- 전체 테스트 82개가 통과해(6개 스킵) 전략, 시장 데이터, 알림, 프런트엔드 자산의 정상 작동을 반복적으로 확인합니다.【08ab47†L1-L3】

## 3. 할루시네이션 검증 결과
- 문서와 코드가 주장하는 기능(다중 지표 기반 AI 분석, 오토파일럿 자동 주문, Synology Chat 알림 등)은 실제 모듈과 테스트로 뒷받침됩니다.
- 가상 브로커, 시장 데이터 무결성 검사, 모멘텀 폴백 전략 등도 모두 코드로 구현돼 있어 “겉모습만 있는” 허상 구조는 발견되지 않았습니다.

## 4. 자동매매 적합성 평가
- **데이터 안전장치**: 캔들 무결성 점수, 업비트 연결 실패 시 합성 데이터 경고, 자가 복구 루틴으로 비정상 데이터를 차단합니다.【F:backend/autopilot.py†L303-L432】【F:backend/market.py†L778-L892】
- **리스크 관리**: 손절·익절·트레일링 스톱, 포지션 크기 제한, 신뢰도 하한선이 오토파일럿 루프에 내장돼 있습니다.【F:backend/autopilot.py†L332-L380】【F:backend/autopilot.py†L585-L605】
- **AI 확장성**: 급등락 탐지, 기관 뉴스, 모멘텀 대체 전략, 손실 복구 플레이북 등 고급 분석이 준비돼 있어 실전 운용에도 활용 가능성이 높습니다.【F:backend/ai.py†L742-L915】【F:backend/ai.py†L1108-L1194】

## 5. 추가 개선 제안
1. **전략 템플릿 스튜디오**: RSI·MACD·거래량 조건을 그래픽으로 조합해 오토파일럿으로 전송하는 UI/백엔드 엔드포인트를 마련하면 사용자 커스터마이징이 강화됩니다.
2. **실거래 안전장치**: 업비트 실 계정 사용 시 하루 손실 한도, 거래 횟수 제한, 체결 알림 확인 절차를 추가하면 리스크 통제가 더 확실해집니다.
3. **자동 검증 리포트**: 현재 `pytest` 결과를 기반으로 HTML 리포트를 생성해 배포 전 QA 증적을 자동 보관하는 기능을 제안합니다.

## 6. 결론
- 현재 코드베이스는 다중 지표 기반의 AI 분석과 자동 주문 실행을 모두 갖춘 **실전 수준**의 자동매매 플랫폼으로 평가됩니다.
- 추가 제안 사항을 순차 도입하면 “메이저급” 요건(사용자 맞춤 전략 디자이너·강화된 실거래 통제·QA 리포팅)을 충족시키는 방향으로 발전할 수 있습니다.
