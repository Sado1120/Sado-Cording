# CryptoHopper 벤치마크 메모

공개 자료(제품 페이지, 소개 영상, 블로그 포스트 등)를 기반으로 CryptoHopper가 제공하는 핵심 기능을 조사하고 Sado Trade Bot이 참고할 만한 개선 아이디어를 정리했습니다.

## 1. 플랫폼 개요
- **클라우드 기반 24/7 운영**: 사용자가 PC를 켜두지 않아도 서버에서 지속적으로 전략을 실행합니다.
- **거래소 멀티 커버리지**: 업비트는 지원하지 않지만, 바이낸스·코인베이스·OKX 등 주요 글로벌 거래소를 동시에 연결합니다.
- **자동매매 + 카피트레이딩 허브**: 자체 전략을 운영하면서도 다른 트레이더의 설정을 구독하거나, 전략을 마켓플레이스에 판매할 수 있습니다.

## 2. 주요 기능과 벤치마킹 포인트

| CryptoHopper 기능 | 설명 | Sado Trade Bot 적용 아이디어 |
| --- | --- | --- |
| **전략 디자이너 (Strategy Designer)** | 드래그 앤 드롭 UI로 인디케이터/조건을 조합해 봇을 설계하고 백테스트 | 프런트엔드에 조건형 빌더 UI를 추가하거나, FastAPI에 인디케이터 조합식 스키마를 도입해 고급 사용자가 커스텀 전략을 설계할 수 있도록 지원 |
| **마켓플레이스 (Marketplace)** | 전략, 시그널, 템플릿을 사고파는 생태계 | AI 추천 TOP5·포트폴리오 결과를 외부 공유 가능한 JSON 템플릿으로 저장하고, 내부 팀 간 재사용 마켓을 마련 |
| **카피 트레이딩 (Mirror Trading)** | 상위 트레이더의 포트폴리오를 자동 복제 | Synology 팀 계정 간에 전략 설정을 복제하거나, 회사 표준 전략을 한 번에 배포하는 팀 공유 기능 추가 |
| **시그널 구독 (Signalers)** | 외부 분석가가 제공하는 매수/매도 시그널을 봇에 연결 | 권위 기관 뉴스 외에 제3자 시그널 API를 플러그인 구조로 연결할 수 있도록 시그널 어댑터 인터페이스 설계 |
| **트레일링 기능 (Trailing Stop/Buy)** | 조건을 만족하면 단계적으로 진입/청산해 변동성 대응 | 기존 트레일링 스톱 로직을 강화하고, 트레일링 매수·스탑 로스 폭 자동 조정 기능을 추가하는 방안 검토 |
| **아비트라지 (Arbitrage)** | 거래소 간 가격 차를 이용해 저위험 수익을 추구 | 업비트 단일 거래소 환경에서는 곤란하지만, 향후 글로벌 거래소를 추가 연동할 경우 크로스 거래 전략 템플릿을 준비 |
| **페이퍼 & 백테스트 분리** | 라이브 계정과 별개로 모의투자 계정을 유지 | 현재의 페이퍼 브로커를 다중 인스턴스로 운영해 전략별 실험 공간을 늘리고, 백테스트 결과와 실시간 페이퍼 계정을 하나의 리포트로 묶는 기능 검토 |
| **모바일/알림** | 앱·푸시·텔레그램 등 다중 채널 알림 | Synology Chat 외 Slack·Telegram·문자 모듈을 플러그인식으로 확장하는 노드 설계 |

## 3. 운영/UX 측면 인사이트
- **온보딩 마법사**: CryptoHopper는 가입 직후 목표·위험 성향·초기 자본을 묻는 단계별 마법사로 사용자 진입 장벽을 낮춥니다. → Sado Trade Bot도 Synology 대시보드 진입 시 기본 환경 설정 마법사, 혹은 README에서 바로 사용할 수 있는 "시작하기" 체크리스트를 더 직관적으로 표시할 수 있습니다.
- **성과 리포트 템플릿**: 월별 손익, 전략별 기여도, 거래 내역을 PDF·메일로 배포합니다. → 테스트 통과 후 자동으로 PDF/엑셀 리포트를 생성하거나, Synology Chat으로 정기 보고서를 전송하는 기능을 고려할 수 있습니다.
- **커뮤니티 & 교육 자료**: 웹 세미나, 튜토리얼, 시뮬레이션 예제를 지속 제공해 사용자 학습을 돕습니다. → 공장 설비/업비트 사례에 맞춘 튜토리얼 영상을 README나 대시보드에서 바로 열람하도록 연동하면 유사한 체감을 줄 수 있습니다.

## 4. 우선 적용 제안
1. **전략 템플릿 공유** – 팀 내부에서 검증된 전략을 JSON 형태로 저장/불러오기하여 카피 트레이딩 경험을 지원합니다.
2. **시그널 어댑터 설계** – 외부 API나 리서치 데이터를 연동할 수 있는 추상 클래스를 제공해, CryptoHopper처럼 다양한 시그널을 쉽게 통합합니다.
3. **정기 리포트 자동 배포** – 오토파일럿 실행 결과를 주기적으로 요약해 Synology Chat 또는 이메일로 공유하는 기능을 추가합니다.
4. **온보딩 마법사** – 대시보드 최초 접속 시 단계별 안내를 제공해 필수 설정을 누락하지 않도록 합니다.
